# Hi, I'm Richard 👋

I build macOS apps and tools that make research and everyday work a little easier.

- 🐾 **[Quotakin](https://github.com/richarddemann/quotakin)** — Claude Code and Codex quotas, reset times, and local usage history in your menu bar.
- ↔️ **[Barfold](https://github.com/richarddemann/barfold)** — A Hidden Bar fork with refined native settings and clearer Accessibility setup.
- 📚 **[OpenPaper Relay](https://github.com/richarddemann/openpaper-relay)** — Find and retrieve research PDFs for AI agents, starting with your Zotero library.
- 🔎 **[Zotero for Tinycast](https://github.com/richarddemann/zotero-tinycast)** — Search your Zotero library, open PDFs, and copy citations from Tinycast or Raycast.
- 🐚 **[SiteShell](https://github.com/richarddemann/siteshell-macos)** — Turn websites and local web services into focused macOS apps.
- 🍎 **[Mac app stack](https://github.com/richarddemann/mac-app-stack)** — Choose macOS apps by category or individually and generate a Homebrew setup file.
