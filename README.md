# Hi, I'm Richard 👋

I build macOS apps and tools for research.

- 🐾 **[Quotakin](https://github.com/richarddemann/quotakin)** — Claude Code and Codex usage in your menu bar.
- 📚 **[OpenPaper Relay](https://github.com/richarddemann/openpaper-relay)** — Research paper search and PDF retrieval for AI agents.
- 🔎 **[Zotero for Tinycast](https://github.com/richarddemann/zotero-tinycast)** — Search your Zotero library and copy citations from Tinycast or Raycast.
- 🐚 **[SiteShell](https://github.com/richarddemann/siteshell-macos)** — Websites and local web services as macOS apps.
- ↔️ **[Barfold](https://github.com/richarddemann/barfold)** — Hide menu-bar icons. A fork of Hidden Bar with reworked settings and Accessibility setup.
- 🍎 **[Mac app stack](https://github.com/richarddemann/mac-app-stack)** — A macOS app picker that generates a Homebrew file for installation.
