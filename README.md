# Richard Demann

I build macOS apps and research tools. Much of my work connects the things I use every day: Zotero, research papers, AI agents, and the Mac.

- **[OpenPaper Relay](https://github.com/richarddemann/openpaper-relay)** gives AI agents access to research papers. It checks Zotero first, then looks for an available copy online.
- **[Zotero for Tinycast](https://github.com/richarddemann/zotero-tinycast)** brings your library into Tinycast and Raycast: find a paper, open its PDF, or copy a citation.
- **[Quotakin](https://github.com/richarddemann/quotakin)** keeps Claude Code and Codex usage in your menu bar, with quotas, reset times, and local history.
- **[SiteShell](https://github.com/richarddemann/siteshell-macos)** turns a website or local web service into its own macOS app.
- **[Barfold](https://github.com/richarddemann/barfold)** is my fork of Hidden Bar, with native settings and clearer setup for hiding menu-bar items.
- **[Mac app stack](https://github.com/richarddemann/mac-app-stack)** lets you pick apps for a new Mac and generate a Homebrew file to install them.
